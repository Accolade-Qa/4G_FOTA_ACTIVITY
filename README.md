# FOTA_ACTIVITY

## Overview
FOTA_ACTIVITY is a Windows-focused automation tool with two main parts:
1. A Java backend (packaged as a fat JAR) that handles automation, IO, and logging.
2. A PyQt6 desktop UI that bundles the backend JAR and other assets into a distributable Windows app.

The repository already contains build outputs under `target` (Java) and `ui/dist` (UI).

## Components
- Java backend: Maven project under `src/main/java` with entry point `com.aepl.atcu.Launcher`.
- Python UI: PyQt6 app under `ui/main.py`, packaged with PyInstaller.
- Inputs and outputs: CSV/JSON/Excel files under `input`, `results`, and `output`.

## Directory Layout
- `src/main/java`: Java sources.
- `src/main/resources`: Java resources (logging config).
- `ui`: Python UI, build spec, assets, defaults, runtime, and distribution artifacts.
- `input`: Input datasets such as CSV, JSON, and Excel.
- `results`: Generated results (CSV/JSON).
- `logs`: Log files.
- `output`: Output artifacts generated by runs.
- `screenshots`: Captured screenshots (if produced by runs).

## Prerequisites
- Java 21 (per `pom.xml` compiler target).
- Maven 3.8+.
- Python 3.10+ (recommended for PyQt6).
- PyInstaller (for building the UI).

Python dependencies are listed in `ui/requirements.txt`:
- `PyQt6==6.7.1`
- `openpyxl==3.1.5`

## Configuration
Configuration lives in `config.properties`:
- Serial configuration: `serial.port`, `serial.baud`.
- Input/output paths: `firmware.csv`, `audit.csv`, `firmware.json`, `login.json`.
- Portal login settings: `login.url`, `login.user`, `login.pass`.
- Default device state: `state`.

Important:
- Do not commit real credentials in `config.properties`.
- Use environment-appropriate values for `login.url`, `login.user`, and `login.pass`.

Input data is expected in:
- `input/fota_batch.csv`
- `input/servers.json`
- `input/Server_Inputs.xlsx`

UI defaults are mirrored under:
- `ui/defaults/`

## Build Commands

### Java Backend (fat JAR)
From repo root:
```powershell
mvn -DskipTests package
```
Output:
- `target/FOTA_ACTIVITY-Version-1.0.2.jar`

### Python UI (PyInstaller bundle)
From repo root, using the existing spec:
```powershell
pip install -r ui/requirements.txt
pyinstaller ui/FOTA_UI.spec
```
Output:
- Folder bundle: `ui/dist/FOTA_UI/`
- Executable: `ui/dist/FOTA_UI/FOTA_UI.exe`

## Run
### Java Backend
```powershell
java -jar target/FOTA_ACTIVITY-Version-1.0.2.jar
```

### Python UI
```powershell
ui\dist\FOTA_UI\FOTA_UI.exe
```
